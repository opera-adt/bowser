# Bowser demo: Hawaii

[Bowser](https://github.com/opera-adt/bowser) showing OPERA L3 DISP-S1 surface displacement over the
Island of Hawaiʻi (frame 23211, descending, 2016–2026), reduced for the demo to 240 m pixels and
every sixth date. Click the map for a time series; draw a polygon for area statistics.

Data: OPERA L3 DISP-S1, NASA/JPL-Caltech, from the Alaska Satellite Facility.
This Space is updated from the Bowser repository by `.github/workflows/demo-space.yml`.
